The default action control; exactly one `primary` (green) button per view.

```jsx
<Button variant="primary" icon="circle">Gravar</Button>
<Button variant="secondary">Cancelar</Button>
<Button variant="ghost" size="sm" icon="sparkles">Melhorar notas</Button>
<Button variant="danger" icon="trash-2">Apagar gravação</Button>
```

Sentence case, 1–3 words, bilingual parity. `md` (28px) is the macOS default; `sm` for toolbars inside panels, `lg` for onboarding.
